# Gestouch source provenance

**Current project:** [lustresense/gestouch](https://github.com/lustresense/gestouch) v0.0.1 (`GPL-2.0-only`).

**Inspiration and research:** [Tomclanc/GestureSignv2](https://github.com/Tomclanc/GestureSignv2) and [TransposonY/GestureSign](https://github.com/TransposonY/GestureSign). At time of review both upstream root `LICENSE` files contained GNU GPL v2. We credit these projects for prior work on Windows gestures.

**Important distinction:** GitHub repository `lustresense/gestouch` is **not currently an actual GitHub fork** of GestureSign V2, and the Gestouch v0.0.1 source was independently authored in Rust using public Microsoft API information and behavior observations. No C# source was copied into the initial repository. Selecting GPL-2.0-only is a project licensing decision, **not evidence of copied source or formal fork lineage**.

No upstream logos, icons, language catalogs, or gestures datasets are bundled. Copying/porting GPL source or assets later must be tracked per-file with copyright notices and GPL compliance. Each new dependency and asset needs separate provenance review before release.

Technical audit baseline: [UPSTREAM_AUDIT.md](UPSTREAM_AUDIT.md). GNU GPL copy: root [LICENSE](../../LICENSE).
